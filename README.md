Hotel Booking Analysis Dashboard

Project Description

The Hotel Booking Analysis Dashboard is a Python-based data analysis project that analyzes hotel booking data to understand booking patterns, customer behavior, cancellations, and hotel performance.

The project uses Python libraries to process and analyze hotel booking data and present meaningful insights through visualizations.

Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code
- CSV Dataset

Features

- Hotel Booking Data Analysis
- Booking Cancellation Analysis
- Customer Booking Trends
- City Hotel vs Resort Hotel Comparison
- Data Visualization
- Business Insights

Dataset

The project uses the "hotel_bookings.csv" dataset.

Python Libraries

- pandas
- matplotlib
- seaborn
- numpy

How to Run

1. Clone this repository.

2. Install the required libraries:
   
   "pip install -r requirements.txt"

3. Run the Python file:
   
   "python app.py"

Project Objective

To analyze hotel booking data and identify useful patterns and insights that can help understand hotel business performance.
